Menghapus latar belakang dari foto sangat penting untuk fotografi produk, foto profil, dan desain kreatif. Lumea menjalankan model segmentasi langsung di browser Anda.

### Cara Kerjanya

Lumea menggunakan model MediaPipe Selfie Segmentation untuk mendeteksi subjek dalam foto. Komputasi segmentasi berjalan pada GPU atau CPU perangkat Anda tanpa mengirim data ke server luar.

### Cara Menggunakan

1. **Unggah gambar Anda**: Masukkan foto (JPG, PNG, WebP) ke dalam alat.
2. **Deteksi Subjek**: Model mendeteksi subjek utama dan memisahkannya dari latar belakang secara otomatis.
3. **Penyempurnaan**: Sesuaikan penghalusan tepi dan intensitas penyempurnaan sesuai kebutuhan.
4. **Unduh**: Simpan gambar Anda sebagai PNG transparan.

### Mengapa Memilih Lumea

- **Pemrosesan lokal**: Berbeda dari layanan yang mengirim foto ke server luar, komputasi segmentasi Lumea berjalan langsung di perangkat Anda.
- **Kualitas tinggi**: Unduh PNG transparan yang siap digunakan dalam desain.
- **Tanpa batasan kuota**: Dapat digunakan bebas tanpa perlu membuat akun atau membeli kredit.
